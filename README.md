# Turbo — 用 Token 换速度

ZCode / Codex 并行加速 Skill：激活后以「并行优先」策略执行当次任务，宁可大量消耗 token，也要把总耗时压到最低。

## 安装

把本仓库目录（或其中的 `SKILL.md`）放到你的 skills 目录下，例如：

```text
~/.agents/skills/turbo/SKILL.md
```

ZCode 中位于 `C:\Users\<用户名>\.agents\skills\turbo\SKILL.md`。

## 触发方式

- **自动触发**：说出「太慢了」「加速」「快点」「并行处理」「别磨叽」「用 token 换速度」「不计成本」「别省 token」「随便花 token」「火力全开」「turbo」等话术，或以任何方式表达「不在乎 token/成本消耗、只要快」时立即激活，无需二次确认。
- **手动激活**：`/turbo`

## 工作原理

按四级并行阶梯执行：

| 层级 | 做法 |
|------|------|
| L1 | 互不依赖的工具调用在同一条消息里全部发出 |
| L2 | 预取：第一时间并行读入所有可能相关的材料 |
| L3 | 独立子任务并发派发子代理（Explore / general-purpose） |
| L4 | 大型多阶段任务用动态工作流编排高并发子代理 |

**铁律**（正确性永远优先于速度）：

1. 依赖必须按序 —— 后一步依赖前一步结果时禁止并行
2. 写操作必须分区 —— 两个执行体不得修改同一文件
3. 结果必须汇总 —— 合并去重后再继续，冲突必须显式指出
